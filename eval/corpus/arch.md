# DocuAsk 技术架构

## 文档切分
先按 Markdown 标题分节，再按 800 字符长度切块，相邻块保留 120 字符 overlap，切分时优先在换行处断开。PDF 按页抽取文本后走同样的长度切分。

## 向量化
使用 BGE-M3 模型生成 dense 向量，维度 1024，距离度量为余弦相似度，向量做归一化后存入 Qdrant。

## 混合检索
dense 向量检索（Qdrant，top20）与 BM25 稀疏检索（top20）两路并行，结果用 RRF 融合，RRF 的 k 参数取 60。

## 重排
融合后的候选送入 bge-reranker-v2-m3 cross-encoder 重排，对 top20 重排后取 top5 作为最终引用。

## 答案生成
Ollama 本地运行 qwen3:4b 模型。Prompt 约束：只根据提供的文档片段回答，回答用中文，片段里没有答案就直说，不要编造，关键结论后标注片段编号。

## 向量库
Qdrant 跑在本地 Docker，监听 127.0.0.1:6333，业务集合名为 docuask，点 ID 取"文件名#块序号"的 SHA256 前 16 位转整数，重跑入库幂等不重复。
